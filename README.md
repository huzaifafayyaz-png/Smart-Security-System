# Smart-Security-System
An Arduino Uno R3 security system that detects intruders using an HC-SR04 ultrasonic sensor and triggers audio-visual alarms with a buzzer, LEDs, and TFT display. Features a three-state machine (DISARMED, ARMED, ALARM) with a 3-second grace period, 30-second auto-silence, and non-blocking millis()-based timing.
